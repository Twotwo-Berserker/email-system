# 项目包装总览：「智邮 CloudMail」— AI 增强的全栈邮件系统

## 一句话定位模板

> **基于 SpringBoot3 + Vue3 + LLM 实现的、带智能分析与多协议接入能力的企业级全栈邮件系统**

## 三种岗位视角的「基于 xxx 实现的 xxx 特色 xxx 项目」

| 投递岗位 | 包装公式 |
|---|---|
| 后端开发岗 | 基于 **SpringBoot3 / MySQL / Redis / MinIO** 实现的、**以多级缓存 + 对象存储降级 + 领域事件异步化**为特色的**分布式邮件收发后端**项目 |
| 全栈开发岗 | 基于 **Vue3 + Element Plus + SpringBoot** 实现的、**以 JWT 双令牌无感续期 + WebSocket 实时推送 + AI 结果可视化**为特色的**前后端分离全栈 Web 邮件系统**项目 |
| Agent 开发岗 | 基于 **LLM API（OpenAI/Anthropic 兼容协议）**实现的、**以结构化输出四级容错解析 + 按租户熔断限流 + 规则引擎兜底 + BYO-Key 多租户**为特色的**邮件智能分析 Agent 管线**项目 |

## 面试可讲的差异化亮点（全部有源码支撑）

1. **LLM 输出的工程化容错**：模型即使加了 `response_format=json_object` 仍会返回 Markdown 代码块包裹、中文前言后记、max_tokens 截断半截 JSON——自研解析器采用"宽松抠取 + Jackson 严格解析 + 重试 + 默认值兜底"四级策略，保证分析管线永不因脏输出崩溃。
2. **按用户分桶的熔断器**：避免单个用户填错 API Key 导致全站 LLM 服务停摆，故障半径收敛到租户级；刻意省略半开状态并能在面试中讲清 trade-off。
3. **LLM 不可用时的规则引擎兜底**：关键词/启发式打分（垃圾分、优先级、8 类分类、恶意链接检测）保证系统在无网/无 Key 时功能完整，体现"AI 增强而非 AI 依赖"的设计观。
4. **凭据安全体系**：邮箱授权码与 LLM API Key 使用 AES 加密落库（缺密钥拒绝启动），前端掩码回显，入站回调 HMAC 签名验签。
5. **多协议接入**：自研 Python 零依赖 SMTP/IMAP 协议代理让 Thunderbird/Outlook 直连 Web 邮箱；Cloudflare Email Routing Worker 实现本域地址收信；Message-ID 唯一键 + IMAP UID 兜底的双重去重。
6. **纯 Docker 交付**：9 个服务 Compose 编排、健康检查依赖顺序、多阶段构建、DB migration 脚本分层，一条命令拉起全套环境。

## 风险提示（诚实边界）

- 项目为实训 Demo，规模与真实生产系统有差距，面试中定位为"系统性演练后端/全栈/Agent 工程能力"更稳妥。
