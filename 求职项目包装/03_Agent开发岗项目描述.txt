# Agent 开发岗 — 项目描述（约150字）

**项目名称**：基于 LLM API 实现的具备结构化输出容错与规则兜底的邮件智能分析 Agent 管线

**描述**：
设计邮件场景 LLM 分析管线，对来信输出 spam/priority/risk/分类/actions 结构化 JSON 契约。①Prompt 按角色-任务-Schema-枚举约束设计，上下文做 HTML 剥离与截断控 Token；②针对 Markdown 包裹、前后缀废话、截断等脏输出，实现 json_object→重试→剥壳→默认值的四级容错解析与防御式取值；③按用户分桶的熔断限流，单租户坏 Key 不影响全局，LLM 失败自动降级规则引擎兜底；④多租户 BYO-Key（AES 加密+掩码），调用日志落库支撑成本延迟观测，并有单元测试保障回归。
